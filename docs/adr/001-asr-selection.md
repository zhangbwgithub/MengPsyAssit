# ADR-001：ASR 选型 — 推荐 paraformer-v2

> 状态：**推荐已定，待陛下最终确认** · 日期：2026-08-25 · 决策者：陛下（大统领提交推荐）
> 背景：咨询记录助手需要「录音 → 带说话人标注的转写稿」，单段录音最长 180 分钟，双说话人（咨询师 T / 来访者 P）。

## 候选范围（三个，均实测）

| 候选 | 模式 | 官方规格（已核实） |
|------|------|-------------------|
| paraformer-v2 | 异步文件转写 | ¥0.00008/s（≈¥0.29/小时）；RPM 1200；月免费额度 36000s；支持说话人分离（建议 ≤2h）；句级时间戳 |
| qwen3-asr-flash | 同步短音频 | ¥0.00022/s；≤5 分钟 / 10MB；无说话人分离、无时间戳 |
| qwen3-asr-flash-filetrans | 异步文件转写 | ¥0.00022/s；≤12h / 2GB；句级时间戳；官方模型页明确**不支持说话人分离** |

## 分析与定夺

**刚需淘汰**：说话人分离（T/P 映射）是系统核心功能（S2 增量依赖），官方支持范围仅 Paraformer 系列 / Fun-ASR / Qwen-Audio-3.0-ASR-Flash-Filetrans——三个候选中**只有 paraformer-v2 支持**，qwen 两候选直接出局（CER 略优但无法完成主链路）。

**成本**：180 分钟/段，paraformer-v2 ≈ ¥0.86，qwen 系 ≈ ¥2.38（且后者还做不到分离）。另有每月 10 小时免费额度。

**残余风险与对策**：
- 合成音频验证 ≠ 真实口音/方言/电话音质下的表现 → S5 端到端验收用真实录音复测（用户自愿提供的脱敏样本）
- 打断重叠场景 CER 偏高（17%）是三家共性（12%/10%/17%）→ 说话人分离本身全对，文字稿可编辑（S2）兜底
- 180 分钟 > 官方"分离建议 ≤2h"为建议值非硬限 → S1 分片上传落地后用真实长音频实测一次

## 结论

**推荐 paraformer-v2 作为唯一 ASR 实现**（S0 的单一 ASRProvider 实现；qwen 系留作 P3 增强期的可选第二实现）。
理由一句话：**唯一满足说话人分离刚需、价格最低三分之一、实测分离一致率 100%、延迟 3.3s 满足异步转写场景。**
