# desktop/ — Tauri 桌面采集端

**状态**：🕐 P2 阶段启动，当前为预留目录。

## 定位

**独立于会议软件**的语音采集端（豆包模式）：在腾讯会议等会议软件开会时，实时获取语音输入。

## 核心技术

| 平台 | 系统音频环回方案 |
|------|----------------|
| Windows | WASAPI loopback（首选，免装驱动） |
| macOS | ScreenCaptureKit（需 macOS 13+） |

## 架构红利

双通道录音 = 免费的说话人分离：

- 麦克风通道 = 咨询师本人 → **T**
- 系统环回通道 = 会议中对方声音 → **P**

在线场景无需聚类算法，T/P 标注天然正确。

## 技术选型

- Tauri 2.0（Rust 内核，体积小，跨平台）
- 平台采集层隔离为极薄接口（`trait AudioCapture`），90% 代码跨平台共享
